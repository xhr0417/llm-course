# 示例文档 A：注意力机制

注意力机制（Attention）让序列中的每个位置根据相关性对其它位置加权求和。
在 Transformer 中，注意力由 Query、Key、Value 三组投影组成：

- Q 与 K 的点积衡量相关性，除以 √d 防止数值过大；
- 对分数做 softmax 得到归一化权重；
- 用权重对 V 加权求和得到输出。

多头注意力（Multi-Head Attention）把表示空间切成多个头，
每个头独立做注意力，最后拼接后再投影。这样模型可以同时关注
不同的关系模式（语法、指代、位置等）。

自注意力（Self-Attention）的复杂度是 O(n²·d)，序列长度翻倍，
计算量变为四倍——这是长上下文的主要瓶颈之一。
