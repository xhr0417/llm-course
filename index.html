  3. 优化器：SGD → Momentum → Adam — SGD、Momentum、Adam 完整推导与算例，AdamW 解耦正则，优化器竞赛演示。
  4. 模型评估与泛化：指标、过拟合与正则化 — 混淆矩阵计算器、四大指标、不平衡数据陷阱、L2、Dropout。
  5. 数值稳定：梯度爆炸/消失、初始化、BN 与残差 — 连乘的威力、Sigmoid 饱和、Kaiming 初始化、BatchNorm 算例、ResNet 残差。
  6. 循环神经网络：RNN → LSTM → GRU — 参数共享、BPTT 长程依赖、LSTM 三门一状态、GRU、Deep RNN（历史演化，保持冻结）。

  9. BERT：Encoder-only 与双向理解 — 三种 Embedding、[CLS]/[SEP]、Attention Mask、MLM、80/10/10、NSP。
  10. GPT：Decoder-only 与文本生成 — Next Token Prediction、训练并行、推理循环、Temperature、Top-K/Top-P。
  11. 现代 LLM 架构：技术演化视角 — LayerNorm→RMSNorm、绝对位置→RoPE、ReLU→SwiGLU、MHA→GQA、KV Cache——按技术演化组织。
  12. PyTorch for LLM：动手之前的必备工具箱 — shape 操作、广播、matmul/einsum、nn.Module、autograd、DataLoader、训练循环、checkpoint——能读懂并写出 small LLM 代码。
  13. Build Your Own Small LLM（上）：组件篇 — Lab 1-7：BPE Tokenizer → RMSNorm → RoPE → Attention → SwiGLU → Transformer Block → Decoder-only LM，每步可运行可验证。
  14. Build Your Own Small LLM（下）：训练篇 — Lab 8-14：数据准备 → 预训练 → 评估 → 生成推理 → KV Cache → SFT → DPO/GRPO 小实验。

  16. GPU Fundamentals：从 SM 到 Roofline — SM/Tensor Core/warp、存储层次、算术强度、Roofline、GEMM 与 kernel fusion、Profiling 入门——理解算力与带宽瓶颈。
  17. Distributed Training：从 DDP 到 3D 并行 — AllReduce/Ring、ZeRO 三阶段、FSDP、张量并行、流水线并行、通信计算重叠与选型指南。
  18. 训练显存、混合精度与 LoRA — 显存构成（参数/梯度/优化器/激活）、FP32/FP16/BF16/FP8、混合精度与 loss scaling、梯度累积、checkpointing、LoRA。
  19. 训练生命周期：Pretrain 与 SFT — 数据清洗、MinHash、配比、warmup/decay、PPL、Chat Template、Loss Mask。
  20. Post-training 与 GRPO：偏好优化全景 — preference data、Reward Model、Bradley-Terry、DPO、PPO/GRPO、RLVR、reward hacking——偏好优化全景图。
